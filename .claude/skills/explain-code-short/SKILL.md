---
name: explain-code-short
description: Explains code in short summary. Use when explaining how code works, teaching about a codebase, or when the user asks "shortly, how does this work?"
---

Keep explanations short and to the point. Focus on the main idea or purpose of the code, rather than going into detailed technicalities. Use simple language and avoid jargon whenever possible. The goal is to provide a clear and concise summary that helps the user understand the overall function or intent of the code without overwhelming them with information.
Also, if the code is part of a larger codebase, try to explain how it fits into the bigger picture and what role it plays in the overall functionality of the project.
